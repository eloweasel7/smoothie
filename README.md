# Spotify Smoothie!

This is a web app that turns your music taste from the last month into a custom smoothie.

## Demo
https://github.com/user-attachments/assets/e3e1c07f-12de-4d7c-8cae-450dff16406c

## How it works
1. Log in with Spotify.
2. The app retrieves your top songs and artists from the last month.
3. The blender will make your smoothie
4. Hover over the ingredients to see more info.

| Smoothie ingredient | What it represents |
|---|---|
| Fruits | Your top 3 songs, chosen by album cover color |
| Smoothie color | A blend of those fruit colors |
| Straw shade | Your top artist's popularity (lighter means more popular) |

## Built with
- JavaScript
- p5.js
- Vite
- Spotify Web API (OAuth 2.0 with PKCE)
